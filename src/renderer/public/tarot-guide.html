塔罗牌与 Dots AI 解读指南

海星塔罗是一款免费的中英文在线塔罗应用。它把完整牌组的本地牌义与 AI 综合分析分开：本地内容随时可读，只有用户主动点击时才会请求 Dots AI。

完整 78 张 Rider-Waite-Smith 塔罗牌

牌组包含 22 张大阿尔卡那和 56 张小阿尔卡那。小阿尔卡那分为权杖、圣杯、宝剑和星币四组。每张牌都可能以正位或逆位出现，两种方向会改变关注重点，但逆位并不简单等于“坏”。

五种三牌牌阵

  • 爱情：观察关系中的现状、张力与下一步。
  • 事业：观察动力、阻碍与可执行方向。
  • 财运：观察资源、风险意识与近期选择。
  • 整体运势：观察当前主题、影响因素与行动重点。
  • 自定义问题：围绕用户自己写下的问题展开三牌解读。

AI 如何形成综合解读？

Dots AI 会收到经过验证的语言、问题、牌阵位置和卡牌正逆位。提示词要求模型先观察大阿尔卡那数量、主导花色或元素、逆位和重复数字，再结合每张牌的位置与相互关系，最后给出近期可使用的反思方向。

隐私、密钥与频率限制

Dots API 密钥保存在 Cloudflare Worker Secret 中，不会出现在浏览器或公开仓库。AI 请求使用匿名频率限制；问题文本只用于生成当次解读。

塔罗描述模式与选择，不提供确定性结果，也不替代医疗、法律或财务专业意见。

English summary

Starfish Tarot is a free bilingual web app with the complete 78-card Rider-Waite-Smith deck, five three-card spreads, upright and reversed local meanings, and an optional Dots AI synthesis. AI requests are validated, rate-limited and sent through a protected gateway; the API key is never exposed to the browser.
